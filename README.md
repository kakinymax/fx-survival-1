# FXサバイバル フォント変更版

ROUND TRENDの外寸は維持し、幅480未満では高さ164px、それ以上では204pxのままです。参考画像に合わせ、ROUND TREND・MARKET INDEX・MIN／MAX／LASTの3行の左端をグラフ枠の左辺に揃えました。MIN／MAX／LASTはラベルと数値を同じ小さなサイズにし、スマホも1行に配置します。狭い幅では字間と見出しサイズを調整し、右上のラウンド番号や大きな指数にも重なり・欠けが生じないようにしています。最も長い縦軸の数字の左余白は2pxに詰め、数字とグラフ枠は8px、右端は12pxを保ちます。目盛りの文字幅に合わせて枠を左へ広げ、Gは統計値の下の独立した段に保ちます。縦軸とラウンド番号の拡大を維持します。

ROUND TRENDの縦の点線は常に4区間を維持します。R01〜R04は各区間1ラウンド（全4枠）、R05〜R08は各区間2ラウンド（全8枠）、R09〜R12は各区間3ラウンド（全12枠）に切り替え、足とラウンド番号を各小枠の中央へ揃えます。R05とR09では右側に3ラウンド分の余白ができますが、未到達の足は描きません。同じ4ラウンドのまとまりで目盛りの最大文字幅が同じ間と急変演出中は足の横位置を保ち、R12は従来の4区間×3ラウンドの配置です。

足は参照画像の緑#7fe0be（上昇）・赤#ff909c（下落）で塗りつぶし、外側に黒の1px枠線を付けます。細い足でも色を残し、過去の足と急変演出中の足で同じ配色を使います。縦軸は開始指数100を縦中央に置き、上下対称の5つの目盛りを等間隔に表示します。基本2刻みで、値幅が大きい時は4・6など2の倍数へ広げます。急変用の予約範囲も両側に収め、演出中に過去の足と縮尺が変わらないようにします。黒い見出し・点線・字体・角丸・ギャップGの位置を維持し、相場値・抽選・精算・履歴・演出の条件と長さを変更していません。

前回の注文画面改善も含みます。R02以降、「前回○倍」を1倍〜100倍の中央に配置し、その下に「前回の相場」「前回の注文」の2行を表示します。本人の確定結果をIDで参照し、ソロの前回倍率ボタンは倍率だけを復元します。100倍の入力欄も24pxの字体で3桁とカーソルが収まり、＋／−・直接入力・キーボード操作を維持します。この注文画面の検証記録はIssue #6にあります。
