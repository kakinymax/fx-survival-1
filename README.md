# FXサバイバル フォント変更版

GitHub PagesのHTTPS試技用の静的ページです。
公開URL: https://kakinymax.github.io/fx-survival-1/
公開ソースはpages/font-change-previewブランチの/ (root)です。

今回の版ではROUND TRENDのロウソク足を上昇は緑、下落は赤で塗りつぶします。白地でも見える濃さにし、過去の足と急変演出中の足で配色を揃えました。塗りの外側に黒の1px枠線を付け、細い足でも色を残します。黒い見出し・点線・整数目盛り・ピクセル字体・角丸とギャップGの位置を維持します。相場・抽選・精算・履歴・急変演出の条件と長さは変更していません。

前回の注文画面改善も含みます。R02以降、「前回○倍」を1倍〜100倍の中央に配置し、その下に「前回の相場」「前回の注文」の2行を表示します。本人の確定結果をIDで参照し、ソロの前回倍率ボタンは倍率だけを復元します。100倍の入力欄も24pxの字体で3桁とカーソルが収まり、＋／−・直接入力・キーボード操作を維持します。この注文画面の検証記録はIssue #6にあります。

ソース: ui/round-trend-colors-20261005 / 968f98ff6ed7c804a0315e77800f760949601c0c。
配色はdraft PR #9、前回の注文画面はmain対象draft PR #7で共有しています。PR #9のbaseはPR #7のブランチで、差分を配色だけに分けています。

配布HTMLを320×568、390×600、390×844、1280×900でローカル検証しました。R01/R02/R12の実際の画素が緑・赤になり、四辺に黒の1px枠線が付くこと、通常／ギャップ、急変演出中に過去の画素と縮尺が固定されること、抽選1回、再読み込みで履歴不変、操作との重なり・横はみ出し・JavaScriptエラーなしを確認しました。公開対象SHAと公開後の検証結果はIssue #8を参照してください。

index.htmlはフロントをIIFEにまとめ、同梱WOFFをFontFaceに直接登録した単独HTMLです。英数字はFX Trend Pixel、日本語はDotGothic16。後者のライセンスをOFL.txtとHTML内に収録しています。
対面・CPU対戦、秘密注文、方向/変動率抽選、確定結果に沿う急変演出、精算を試せます。
GitHub Pagesは静的ページなので、Worker/D1や認証付き戦績APIは実行されません。戦績のオンライン保存、生涯戦績、ランキング、TRIP等の通信機能は未接続です。保存成功を模擬する処理はありません。
