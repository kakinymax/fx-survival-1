# FXサバイバル（仮）

基本ルール v1.0 に基づく、1台を受け渡して遊ぶ2〜6人向けのブラウザゲーム。

静的ファイルは `dist/`。ローカルでは `python -m http.server 4173 --directory dist` で起動します。外部サーバーやアカウントはゲーム処理に使いません。ゲームの途中記録は、このブラウザの localStorage に保存されます。

秘密の注文と精算後の進退を全員の確定後に公開。資産は常時公開。実物の鉛筆・サイコロの入力と、暗号学的乱数によるアプリ抽選に対応します。通常の0円ロスカット、ギャップの負債、永久離脱、12ラウンド自動確定、同率勝利、勝者なしを扱います。

金額は1,000円単位の整数を文字列で保存し、BigIntで演算。精算後の残高を最も近い1,000円に丸め、ちょうど半分は絶対値が大きくなる方向に四捨五入します。最高資産・最大取引額・各ラウンドの結果を記録します。入力中に再読み込みやアプリ切替をすると受け渡し画面に戻り、未確定の入力はリセットします。

計算・ゲーム進行の検証: `npm test`。

WebMCP対応ブラウザでは公開状態の取得と参加者設定からの開始だけを提供します。秘密の注文や進退を読み取るツールはありません。

全員共通のステージを開始時に選択できます。クラシックはv1.0の表をそのまま使用。ドル円は通常0.1〜1%、ギャップ1.5 / 3 / 5%。トルコリラ円は通常0.2〜3%、ギャップ5 / 10 / 20%。通貨のイメージを使ったゲーム用の設定です。方向の50:50とギャップ発生率1/12は全ステージ共通です。アプリ抽選・実物入力・ルール表示は同じ表を使用します。ステージ情報がない以前の保存データはクラシックとして継続します。
