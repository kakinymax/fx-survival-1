# FXサバイバル フォント変更版

GitHub PagesのHTTPS試技用の静的ページです。
公開URL: https://kakinymax.github.io/fx-survival-1/
公開ソースはpages/font-change-previewブランチの/ (root)です。

R02以降の注文画面で「前回○倍」を1倍〜100倍の中央に配置し、その下に前回結果を2行で表示します。
「前回の相場」に上昇／下落・変動率・通常／ギャップ、「前回の注文」に本人の買い／売り・確定損益を表示します。方向・率と損益の数値を14pxにして強調し、相場が下落しても売りで利益になるケースを読み分けやすくしました。初回や本人の前回結果がない場合は表示しません。
対面では現在の手番プレイヤーのIDを確定ログと照合します。ソロの前回倍率ボタンは倍率だけを復元し、売買選択を維持します。
100倍の数値入力も3桁とカーソルが収まる幅を確保し、24pxの文字サイズ、既存の＋／−、直接入力、キーボード操作を維持しています。

ソース: ui/order-previous-result-20261005 / 302ce81a7ca68c5514cbf4b648d6b1f8ff7813f1。
変更はmain対象のdraft PR #7で共有しています。

index.htmlはフロントをIIFEにまとめ、同梱WOFFをFontFaceに直接登録した単独HTMLです。英数字はFX Trend Pixel、日本語はDotGothic16。後者のライセンスをOFL.txtとHTML内に収録しています。
配布HTMLを320×568、390×600、390×844、1280×900でローカル検証し、中央の倍率・結果2行・実際のドット字体・前回結果・倍率復元・再読み込み・対面受け渡し・重なりや横はみ出しがないことを確認しました。100倍の入力はローカルWorker上の6サイズで確認しました。公開対象SHAと公開後の検証結果は下記Issueを参照してください。

対面・CPU対戦、秘密注文、方向/変動率抽選、実際の確定結果に沿う急変演出、精算を試せます。
GitHub Pagesは静的ページなので、Worker/D1や認証付き戦績APIは実行されません。戦績のオンライン保存、生涯戦績、ランキング、TRIP等の通信機能は未接続です。保存成功を模擬する処理はありません。
